# Testing Governance

Required future testing layers:
- unit
- integration
- API
- database
- authorization
- security
- E2E
- regression
- performance where justified

## Rules
- A feature is NOT complete merely because its UI works.
- No fabricated tests.
- No fabricated test results.
- No fabricated security evidence.
- Unverified items must be marked: UNVERIFIED
- Blocked items must be marked: BLOCKED
