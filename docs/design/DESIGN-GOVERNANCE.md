# Design Governance

IMKAN One Design System = VISUAL AUTHORITY.
Zoho WorkDrive = FUNCTIONAL/UX RESEARCH REFERENCE.

The application MUST NOT become a visual copy of Zoho.

## IMKAN One Rules
- Zoho One-like enterprise density
- no marketing-style layout
- no application-specific theme
- no second primary color
- use design tokens
- no hardcoded hex where a token exists
- IMKAN primary token
- shared platform chrome
- no duplicate platform header
- no duplicate platform sidebar
- no duplicate platform account menu
- EN
- AR
- RTL
- LTR
- Zoho Puvi for English where supplied
- IBM Plex Sans Arabic for Arabic where supplied
- 14/12/10px interface scale
- shared button/table/panel/input classes
- dark mode through platform tokens
- no custom application branding

Do not invent new token values.
The supplied IMKAN One Design System document remains authoritative.
