# Security Governance

Security MUST be continuous, not a final phase.

Security requirements MUST include at minimum:
- Authentication
- Authorization
- RBAC
- Tenant Isolation
- Session Security
- Password Security
- MFA-ready architecture
- Rate Limiting
- Input Validation
- Output Encoding
- SQL Injection Protection
- XSS Protection
- CSRF Protection
- SSRF Protection
- IDOR Protection
- Broken Access Control Protection
- Privilege Escalation Protection
- Path Traversal Protection
- File Upload Security
- MIME Validation
- Malicious File Handling
- Signed URLs
- Download Authorization
- Share Link Security
- Token Security
- Audit Logging
- Security Monitoring
- Secrets Management
- Encryption requirements
- Backup security
- Data retention
- Security testing

Security-sensitive features MUST have: `docs/security/<feature>-security.md`
