# Security Architecture

## Threat / Control Model

- **Authentication Bypass:**
  - Control: Strict JWT verification. No unauthenticated routes except `/login` and `/share/public`.
- **IDOR / Cross-Tenant Access:**
  - Control: All DB queries scope by `WHERE org_id = ? AND id = ?`. Use UUIDs v4 to prevent predictable guessing.
- **SQL Injection:**
  - Control: Use Prisma/TypeORM parameterized queries exclusively.
- **XSS / Content Sniffing:**
  - Control: Object Storage signed URLs must enforce `Content-Disposition: attachment` for untrusted MIME types to prevent inline HTML execution.
- **Path Traversal:**
  - Control: S3 keys are generated by the server (UUIDs), not using client-provided filenames.
- **Rate Abuse:**
  - Control: Global rate limiting via Redis on API gateway.

## Evidence
- Tests MUST simulate cross-tenant IDOR.
