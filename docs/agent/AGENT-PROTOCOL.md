# Agent Protocol

THE REPOSITORY IS THE SINGLE SOURCE OF TRUTH.
Conversation history is NOT the project's source of truth.
Any Agent may be replaced by another Agent.
Agents must communicate through repository artifacts, not conversation assumptions.

## Rules for Every Agent
1. Read PROJECT-STATE.md.
2. Read CURRENT-PHASE.md.
3. Read CURRENT-TASK.md.
4. Read CONTEXT-MAP.md.
5. Read only relevant documentation.
6. Avoid unrelated repository scanning.
7. Record important decisions.
8. Record blockers.
9. Update project state after meaningful work.
10. Never claim completion without evidence.
11. Never fabricate tests.
12. Never fabricate external integrations.
13. Never silently change architecture.
14. Never silently change security requirements.
15. Keep final responses concise.
