# Token Policy

- Read-on-demand context.
- Scoped context.
- No unnecessary repository-wide scanning.
- No repeated reading of unchanged files.
- No repeated architecture explanations.
- No duplicated documentation.
- Concise agent responses.
- Machine-readable artifacts where practical.
- Decisions stored in files.
- Summaries instead of historical transcripts.

Prefer: CURRENT-TASK.md, CONTEXT-MAP.md, PROJECT-STATE.md over loading large historical documents.
Never load previous Phase completion reports unless needed for debugging, auditing, or regression analysis.
