# Functional Requirements

## 1. Storage & Organization
- F-101: The system shall allow users to upload files and folders up to organization limits.
- F-102: The system shall support drag-and-drop uploads.
- F-103: The system shall allow creating deep folder hierarchies.

## 2. Team Collaboration
- F-201: **Org Administrators** shall be able to create Team Folders. (Interpretation: Only org ADMIN, not Organizer. Organizer role in Team Folder is for collaboration within existing TF, not for creating new TFs.)
- F-202: The system shall support Admin, Organizer, Editor, and Viewer roles within Team Folders.
- F-203: The system shall allow comments on files and folders. (Out of scope for Phase 05)

## 3. External Sharing
- F-301: The system shall allow users to create public links for files.
- F-302: The system shall allow setting passwords on public links.
- F-303: The system shall allow setting expiration dates on public links.
- F-304: The system shall allow preventing downloads on shared links.
