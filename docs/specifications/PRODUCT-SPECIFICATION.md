# Product Specification

## Overview
IMKAN WorkDrive is a secure enterprise file storage and collaboration platform based on the Zoho WorkDrive functional reference, adopting the IMKAN One Design System.

## Primary Modules
- **My Folders:** Private workspace for individual users.
- **Team Folders:** Shared workspaces for groups.
- **Admin Console:** Tenant-wide administration, user management, and security policies.

## Key Differentiators (from standard cloud storage)
- Emphasis on organization-centric data ownership (Team Folders).
- TrueSync capability for on-demand file streaming to desktop clients.
- Deep, granular role-based access control (RBAC).
