# Sharing and Permissions

## Team Folder Roles
1. **Admin:** Manage members, settings, and all contents.
2. **Organizer:** Add/edit/delete files and folders, share items.
3. **Editor:** Add/edit files, but cannot delete or share externally.
4. **Viewer:** Read and download only.

## Granular File Permissions
- Users can share specific files from My Folders or Team Folders with internal users.
- Internal sharing roles: View, Edit, Comment.

## External Sharing
- **Link Types:** Anyone with link, Anyone with link + Password.
- **Controls:** Expiration date, disable download/print, request user data (PROPOSED).

## Permission Inheritance
- Folders inherit permissions from their parent Team Folder.
- Explicit permissions on a file override folder-level restrictions (if more permissive).
