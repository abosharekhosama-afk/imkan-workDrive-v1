# Zoho WorkDrive Research Overview

## Product Overview
Zoho WorkDrive is an online team storage and collaboration platform. It provides a unified workspace for organizations to store, share, and manage files securely.

## Core Paradigms
- **Team Folders:** Shared workspaces for specific teams or projects. Members of a Team Folder automatically get access to its contents based on their assigned role (Admin, Organizer, Editor, Viewer).
- **My Folders:** Personal workspace for private files, which can be selectively shared.
- **TrueSync:** Desktop client capability allowing users to access cloud files without consuming local storage space.
- **External Sharing:** Secure public links with passwords, expirations, and download restrictions.
