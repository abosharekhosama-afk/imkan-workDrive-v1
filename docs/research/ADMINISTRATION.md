# Administration

## Organization Admin Console
- **Dashboard:** Storage usage, active users, total teams.
- **Users:** Provisioning, deprovisioning, role assignment (Super Admin, Admin, Member).
- **Groups:** Create user groups for easier permission assignment.
- **Data Administration:** Ability to transfer ownership of files from a deleted user.
- **Settings:** Configure sharing restrictions (e.g., disable external sharing globally), custom branding (PROPOSED).

## Storage Management
- View quota utilization by user and by Team Folder.
