# Collaboration

## Comments
- Users can leave comments on files and folders.
- Supports @mentions to notify specific team members.
- Comment threads can be resolved.

## Activity Timeline
- Every file/folder has an "Activity" tab showing a chronological log.
- Tracks: Created, Renamed, Moved, Shared, Downloaded (PROPOSED), New Version Uploaded.

## Notifications
- In-app bell icon and email digests.
- Alerts for: Shares received, @mentions, access requests.
