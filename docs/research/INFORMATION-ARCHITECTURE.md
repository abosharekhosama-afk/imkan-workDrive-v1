# Information Architecture

## Application Map
- **Home / Dashboard**: Quick access to recent files, favorites, and unread comments.
- **My Folders**: Personal, private storage.
- **Team Folders**: Collaborative workspaces.
- **Shared with Me**: Files shared by other internal users.
- **Recent**: Chronological list of accessed files.
- **Favorites**: Starred files/folders.
- **Trash**: Deleted items pending permanent removal.

## Additional Modules
- **Search**: Global search bar with advanced filtering dropdown.
- **Notifications**: Alert panel for shares, comments, and mentions.
- **Admin Console**: Separate area for organization management, users, and security settings.
- **Settings**: User profile and app preferences.
