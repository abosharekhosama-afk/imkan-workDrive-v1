# Feature Inventory

## 1. File & Folder Management
- Create folders/subfolders
- Upload files/folders (Drag & drop support)
- Rename, Move, Copy, Delete, Restore, Permanent Delete
- File versioning (Version history view, restore version)

## 2. Organization & Discovery
- Recent items view
- Favorites/Starred items
- Trash lifecycle (retention policies)
- Advanced Search (filter by type, author, date, location)
- Sorting (Name, Size, Modified Date)
- List and Grid views

## 3. Sharing & Collaboration
- Team Folders (Public to org or Private to members)
- Internal sharing (specific users/groups)
- External sharing (Public links)
- Link controls (Password, expiration, disable download)
- Comments on files/folders
- Activity timeline/Audit trail

## 4. Administration
- Member management (Invite, suspend, delete, roles)
- Storage quotas
- Data retention policies
- Device management (sessions)
- Security controls (MFA requirements, IP restrictions)
